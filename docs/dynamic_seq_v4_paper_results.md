# 时序动态前馈模型（GRU + 全传感器）—— 论文结果稿

模型：`configs/dynamic_seq_v4.pt`（torch.save）｜配置：`configs/dynamic_seq_v4.json`
代码：`model/seq_model.py`（模型定义）、`model/fit_dynamic_seq.py`（训练/评价）、
`control/forward_seq_runtime.py`（运行时）、`model/verify_seq_runtime.py`（一致性验证）
平台：rig2 球面关节，100Hz 控制回路，4 个干净会话（slew_limit=20，超限 0.0%）

---

## 1. 方法

### 1.1 残差式架构（零回归保证）

```
u_ff(t) = g_static(q_d(t))  +  clip( Δu_θ(x_{t-L+1..t}) , ±cap )
          └── 静态逆映射（既有成果）    └── 时序模型修正
```

`cap = 0` 时**逐位**退回纯静态前馈——已机器验证：16000/16000 拍与纯静态基座完全一致
（`model/verify_seq_runtime.py`）。这使模型可以安全地逐级放开，不存在"装上就退化"的路径。

### 1.2 输入特征（22 维/拍，全部传感器）

| 组 | 维数 | 来源 |
|---|---|---|
| 实测状态 | 4 | `q, q̇`（动捕，q̇ 用因果零滞后多项式核） |
| 期望轨迹 | 6 | `q_d, q̇_d, q̈_d`（控制器给定，**外生**） |
| IMU | 6 | 陀螺 3 轴 + 加计 3 轴 |
| 张力 | 4 | 力传感器 ch1–ch4 |
| 上拍动作 | 2 | `u_{t−1}`（实际下发的总 offset） |

**全部特征因果可用**：`q̇/q̈_d` 用对过去 31 拍做二次拟合、取 τ=0 处系数的零滞后因果核，
不需要未来数据、不引入相位滞后。

### 1.3 监督信号（收敛段监督，关键设计）

```
Δu(t) = u_recorded(t) − u_base(q_d, q̇_d)      只在 |q − q_d| < 1° 的收敛段取样本
```

**为什么必须筛收敛段**：`u_recorded` 里含 PID 反馈输出。不筛时，标签成为
`(q, q_d)` 同拍特征的确定性函数——实测同拍 22 维特征的线性回归就达
**R² = 0.986 / 0.989**，模型会退化为"复刻 PID"而非"学被控对象需求"，
离线指标再漂亮也没有意义。收敛段内 PID ≈ 0 → 标签 ≈ 该目标状态真实需要的动作量。

### 1.4 训练

GRU(hidden 32, L=10) + 线性头；归一化折进模型 buffer；Adam，MSE，batch 256，60 epoch，
按验证 MSE 选最优权重；训练/推理**全部走 torch**（`device="auto"` → cuda 可用即用）。

## 2. 主结果：LOSO 留出（4 会话）

| 留出会话 | 零修正基线 fb / lr | 时序模型 fb / lr | 改善 |
|---|---|---|---|
| session_…200340 | 51.92 / 53.62 | **5.73 / 6.72** | −89.0% / −87.5% |
| session_…200639 | 79.33 / 75.73 | **16.66 / 16.09** | −79.0% / −78.8% |
| session_…200928 | 46.07 / 42.74 | **6.75 / 7.39** | −85.3% / −82.7% |
| session_…201038 | 36.67 / 42.01 | **7.97 / 5.06** | −78.3% / −88.0% |
| **平均** | **53.50 / 53.53** | **9.28 / 8.82** | **−82.7% / −83.5%** |

全量训练（内部 15% 验证）：Δu RMSE `52.27 → 3.56`（−93.2%，R²=0.995）/ `53.25 → 3.24`（−93.9%，R²=0.996）。

**逐折一致**（−78% ~ −89%），无单折离群——这是离线筛选能通过的最低要求。

## 3. 架构对照：时序 vs 无时序（同协议、同会话、同基座）

| 模型 | 留出残差 RMSE fb / lr | 相对零修正 |
|---|---|---|
| 静态基座（零修正） | 53.20 / 53.75 | — |
| **v3_static**：MLP(6 维轨迹特征，无时序) | 14.29 / 14.75 | −73.1% / −72.6% |
| **本模型**：GRU(22 维，含全传感器，L=10) | **9.28 / 8.82** | **−82.7% / −83.5%** |

→ 时序架构在同等协议下**再降 35% / 40%**，且输入信息更多（传感器）但参数仅 26KB。

## 4. 消融：传感器到底贡献了多少（含同维数对照）

在 MLP 残差模型上做 4 折 LOSO，逐一加入传感器组：

| 特征组 | 留出 RMSE fb / lr | 相对无传感器 |
|---|---|---|
| 轨迹特征（6 维，= v3_static） | 14.29 / 14.75 | — |
| + IMU（6 维） | 14.83 / 14.78 | +3.7% / +0.1% |
| **+ 张力（4 维）** | **12.15 / 12.28** | **−15.0% / −16.7%** |
| + IMU + 张力 | 12.68 / 12.50 | −11.3% / −15.3% |
| **【对照】同维数打乱传感器列** | 14.04 / 14.96 | −1.8% / +1.4% |

**结论**：张力传感器带来 **15~17% 的真实改进**（逐折一致，且远优于同维数打乱对照的 ~0%）；
IMU 单独加入无效。这支持"张力反映关节弹性/传动状态，是纯轨迹特征看不到的动态信息"。

## 5. 工程验证（防静默失效）

| 检查 | 方法 | 结果 |
|---|---|---|
| 训练↔运行时特征一致 | 同会话原始流逐拍喂运行时缓冲，与训练窗口逐元素比 | max(\|Δ\|/std) = **2.4e-07** ✅ |
| 零回归 | cap=0 与纯静态基座逐拍比 | **16000/16000 逐位一致** ✅ |
| 反解（若走逆模型路线） | — | 结构性不可辨识，已否决 → 见 `docs/forward_seq_inverse_findings.md` |

一致性检查实际抓到两处**静默** train/serve skew（都不报错、上机才会暴露）：
① 上拍动作特征错位一拍（训练用 `u_t`，运行时只能给 `u_{t−1}`，该列差 4~9 offset）；
② `q̇/q̈_d` 的 dt 口径不一致（训练写死 0.01，`load_session` 用实测 0.0101）。
修正后降到 float32 舍入量级。
