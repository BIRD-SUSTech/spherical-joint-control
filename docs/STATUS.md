四者主控方程：

```
#1  u = PID(q_d − q)
#2  u = g(q_d)                    + PID(q_d − q)
#3  u = g(q_d)   + f_MLP(q_d,q̇_d,q̈_d)          + PID(q_d − q)
#4  u = g(q_d)   + clip(Δu_GRU(全传感器历史), ±cap) + PID(q_d − q)
```

`#3`/`#4` 均为**残差式**：修正项置零即逐位退回 `#2`（零回归保证，已机器验证）。

## 4. 已关闭的路线（代码已删，结论保留）

- **反解 F（逆动态）**：结构性不可辨识 → 否决。
  根因：舵机为**位置控制**，指令 u(t) 就是实测角 q(t+8拍) 的线性像（实测 r=0.96~0.99），
  历史特征里的 q 已完全暴露 u → `(历史,u)` 零信息增量 → ∂F/∂u 无法辨识
  （打乱 u 或完全去掉 u 输入，留出 RMSE 都不变；与激励类型、数据量、模型容量无关）。
  故采用**残差式**（#3/#4）而非逆模型。
- **速度前馈 τ 相位超前式**：离线 RMSE 比加性线性式差 42~48%（τ 式 ≡ 系数 g′(q)·τ，
  多引入有害的 q 依赖）→ 未采用。
- **单拍 q̈ 动态项**：q̈ 项的独立解释力极弱（仅 q̈ 的 R² 仅 0.02~0.30），
  且早期结论被 slew_limit=2.0 污染（18~60% 样本被削）→ 已修正。

## 5. 纪律（写入结论前必须满足）

1. **离线指标不作合并依据**（已三次证伪：离线改进而上机变差）。
2. **多轨迹验证**（单轨迹 A/B 已三次误判）。
3. **A/B 两段只差一个字段**，且必须与各自基座对跑。
4. **零回归**：修正项置零须逐位退回基座（机器验证，不靠读代码）。
5. **新特征必须与"同维数无信息对照"比**（打乱列），才可宣称有效。
