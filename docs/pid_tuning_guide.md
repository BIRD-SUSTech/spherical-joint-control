# PID 整定指南（前馈辅助下的反馈侧整定）

> 目标：抑制 0.61s（1.5Hz）"顿挫"极限环，同时不恶化跟踪精度。
> 背景：顿挫感已诊断为反馈环激发的固有振荡（前馈占 81.7% 且干净），问题在反馈侧。

---

## 一、本系统整定的特殊性（与经典整定的区别）

| 因素 | 影响 |
|---|---|
| 前馈占 81.7% | 反馈只需"小范围微调"，增益应远低于纯反馈时代 |
| 倒立摆负刚度 | 增益有下界（太低球杆会倒） |
| 缆绳柔度 | 净刚度决定 1.5Hz 固有频率 |
| 动捕延迟 + 死区 + 静摩擦 | 极限环配方，增益越高越易振 |

**关键**：当前 `Kp=8, Ki=1, Kd=2.5` 是"无前馈纯反馈"时代复刻的参数。前馈承担大部分驱动后，反馈仍留高增益 = 1.5Hz 极限环的放大器。

---

## 二、三阶段整定流程（P → D → I）

### 阶段 1：Kp 扫描（最优先）

```
Kp: 8 → 4 → 2 → 1，固定 circle15 + v7前馈 + fade 1.0
```

- 有前馈托底，Kp 可大胆降（球杆不会倒）；
- 预期：Kp 降 → 极限环衰减 → 顿挫减轻。

### 阶段 2：Kd 扫描（阻尼）

```
固定阶段 1 最优 Kp，Kd: 2.5 → 1 → 0.5 → 0
```

- Kd 是阻尼项，吸收振荡能量；
- 注意：动捕差分噪声大，Kd 过大会放大高频抖动（若出现，改用 IMU 陀螺做 D）。

### 阶段 3：死区 + Ki（极限环"配方"）

```
死区: 0.2 → 0.1 → 0.05；Ki: 1 → 0.5 → 0.2
```

- 死区 + 积分 + 静摩擦是极限环经典来源：进死区→积分累积→冲出死区→跳→再进死区；
- 减小死区或降 Ki 可打断这个循环。

---

## 三、判据（顿挫感客观化）

不再靠"手感"，用数据：

1. **残差 std**：锯齿越密/越深，std 越大；
2. **0.61s 振荡分量**：残差自相关首个峰（顿挫周期）的幅值，应随 Kp 下降而衰减；
3. **MAE**：跟踪精度，不恶化是底线；
4. **时间图锯齿**：valuation --all 的 track_time.png 肉眼可查。
