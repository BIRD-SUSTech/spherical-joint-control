# 缆驱动球关节系统 —— 顶层重构设计文档

> 状态：设计共识稿（讨论收敛版，未实现代码）

> 前置：本文档取代 `docs/feedforward_design.md` 的架构地位；后者降级为"前馈子系统的历史设计快照"，其中与本文冲突处以本文为准。

## 1. 背景与目标

项目从"能跑的最小闭环"逐步堆叠成多套并存实现，同一概念有多个互相矛盾的口径，已到必须从头梳理的程度。本文档做四件事：

1. 明确**新基座**：以 `example_code/steering_motor`（已验证的最小闭环 + STM32 固件）为唯一出发点；
2. 定义**唯一事实源**（Single Source of Truth）：每个物理/数据概念只保留一个口径；
3. 给出**分层架构**：每层可独立验证、可回退，新模块以"旁路"接入，保证不"负优化"；
4. 制定**数据驱动找优化点**的方法论：不猜测死区/静摩擦，让固有问题在数据中显形，再决定建模复杂度。

不是代码多，而是**真值不唯一**。同一概念存在多套互相打架的实现：

## 4. 新基座：底层约定（唯一真值源）

以下约定以 `example_code/steering_motor` 的**固件实际行为**为准（`Core/Src/main.c` + `usart.c`），是 L0 层不可再分的物理事实。

### 4.1 串口协议

- 帧格式：`0xAA | id(1B) | int16_be(2B) | 0x55`，共 5 字节。
- `id=1` → 前后对 `Coupled_Servo(CH3, CH1, S3_MID, S1_MID, offset, comp)`
- `id=2` → 左右对 `Coupled_Servo(CH4, CH2, S4_MID, S2_MID, offset, comp)`
- `id=0` → **完全放线**（四路减 `RELAX_OFFSET`，杆会垂落），M1 实机确认会过度放线，**暂不使用**。
- 运行约定：正常退出与 guardian 急停都**回中位** `send_pair(0,0)`（offset=0 → 固件 `Sx_MID` 张紧中立位），保持缆张紧，不放线。
- 耦合在**固件内**完成：一端 `+offset`、另一端 `-offset`；主机只发 2 路差分。

### 4.2 指令空间

- 指令 = **PWM offset（int16）**，物理上是舵机脉宽的微秒级偏移。
- 固件 `MOVE_RANGE` 宏未实际使用，**删除**；offset 不做固有限幅，安全界定义在**关节角空间**（§9.6，阈值 70°）。
- offset → 关节角的增益未知，由标定确定（§7.3），也是前馈 L1 级（2×2 增益矩阵）要辨识的对象；增益标定前，激励幅度逐步保守放大。
- 中位脉宽：`S1_MID=1500, S2_MID=1600, S3_MID=1500, S4_MID=1500`（`S2_MID=1600` 是硬件标定差异，保留）。
- 共模预紧 = 固件 `Coupled_Servo` 的 `comp` 参数（当前 `main.c` 写死 0）。预紧是**固件层共模**，不是主机层量。

### 4.3 最小闭环参考行为（`CloseLoop/main.py`）

- 双独立 PID（左右、前后），输出单位 offset，`KP=8, KI=1, KD=2.5, DB=0.2, AP=0.3`。
- 动捕读取：`PyGetLastFrameOfMocapData()` 轮询最后帧，取 SDK 扩展欧拉角；刚体按 `rigid_bodies[0]` 下标取。
- 左右（id=2）← 动捕 `pitch`，前后（id=1）← 动捕 `roll`（此为 example_code 实测，仍需 §7.3 标定确认映射与符号）。
- 控制频率 ≈ 100Hz（非严格定时）。

### 4.4 关键简化

`excitation.py` 的差分/共模思想保留，但编码函数从"差分/共模 → 4 路归一化"简化为"两轴差分 → 2 路 offset"。共模（预紧）下沉到固件 `comp`。

## 5. 分层架构（L0–L5）

```
L0 硬件/协议层   协议帧编解码、串口、舵机 offset 限幅、放松/急停、动捕读帧
L1 采集层        统一 CSV schema + 时间戳 + segment 语义 + 多线程采集编排
L2 激励层        开环差分激励（Lissajous/chirp/阶跃/往返）+ 安全监护
L3 控制层        最小闭环 PID（唯一控制器，u_fb）
L4 建模层        前向 F / 残差结构分解 / 前馈 g（纯离线，读 L1 数据）
L5 集成层        u = u_ff + u_fb，u_ff 默认 0（可关）
```

## 7. 数据驱动方法论：不猜测，让问题显形

### 7.1 核心原则

**"不猜测" ≠ "不建模"，而是"每个假设都配一个判别性实验，用数据裁决"。**

- 假设"存在静摩擦/死区" → 判别实验：微幅阶跃，测"offset 变化而姿态不动"的死区宽度（可直接量化）。
- 假设"存在换向迟滞" → 判别实验：往返 chirp/三角波，测 `q(u)` 上升/下降沿滞回环宽度。
- 假设"增益/柔度标定错" → 判别实验：准静态扫幅，测 `q` 对 `u` 的斜率与标称是否一致。

### 7.2 已有证据（离线前向建模 + M1 实机观察）

前向模型 F 的现有结论已经能回答一半问题：

- **1-step 误差 ≈ 0.10°/0.14°**（前后/左右），已接近动捕噪声地板 → 前向映射本身不难学。
- **free-running rollout 发散严重**：`real_60seg` rollout MAE 0.71°/1.21°、FDE 欧氏 5.8°；`real_randomval` 更差。

**解读**：单步能拟合、多步漂移 = 系统存在**记忆效应**（迟滞/静摩擦/缆松弛/舵机动态），而非纯静态非线性。这**正是"固有问题"的量化证据**——不需要猜。

M1 实机（`--hold` 阶跃，2026-09-05）补充的直接观察，全部指向同一批固有问题：

| 实机观察 | 量化 | 指向的固有问题（§7.3 对应动作） |
| --- | --- | --- |
| 轴间瞬态耦合 | lr 阶跃 5° 扰动 fb ≈1.5° | 2×2 增益/解耦（前馈 L1 级） |
| 增益非线性 | fb 5° 稳态 ≈0.041°/offset vs 近中位 ≈0.023°/offset | 反对单一标量增益，分方向/工作点标定 |
| 低幅游走 | fb 5° 位 std≈0.20°（> 噪声地板 0.06°），out 58–102 游走 | 疑似静摩擦微极限环 |
| 阶跃超调 | 5° 目标冲到 ≈8.6°（≈+72%），1.6–2.0s 收敛 | PID 整定 / 前馈欠补偿 |
| 持中位 DC 偏置 | (0,0) 需 out fb=−36 / lr=−25 | 重力/不对称补偿（可进前馈基座） |

> 数据来源：共享目录 `expriment_workspace/M1_verification/`（实验记录 + `data/*.csv`）。

M3 实机（标定 + baseline，2026-09-06）把上述观察固化为数字：

**符号/增益标定（`calibrations/rig1.json`）**：前后←roll 正号、左右←pitch 正号（与 M1/M2 一致，无 FLIP 反转）；增益矩阵对角占优（交叉项 <0.8%）→ 2×2 解耦前馈前提成立。

| 增益 | 值（°/offset） |
| --- | --- |
| 前后 | 0.0357（聚合 ±20–60 offset） |
| 左右 | 0.0428 |
| 交叉 | <0.0003 |

**系统当前上限（baseline，u_ff=0，前馈 A/B 对照组）**：

| 轨迹 | 稳态 MAE | 峰值误差 |
| --- | --- | --- |
| hold(0,0) 30s | fb 0.088° / lr 0.089°（≈噪声地板 2 倍内） | ≤0.41° |
| circle(5°,6s) 60s | fb 0.65° / lr 0.62° | 2.16° / 1.72°（象限过渡处，相位滞后主导） |

- ramp-in 2s 使 circle 启动超调 **−55%**（fb max\|e\| 4.76°→2.16°）。
- 峰值误差集中在圆象限过渡（速度/相位滞后）→ **前馈的直接优化对象**。

M4 实机开环扫频（2026-09-07）补充的固有问题证据：

| 观察 | 量化 | 指向 |
| --- | --- | --- |
| 增益幅值依赖 | ±5° 有效增益 fb 0.057 / lr 0.059 °/offset，为 M3 小幅标定（0.0357/0.0428）的 **1.4–1.6 倍** | L1 前馈需幅值/工作点相关增益（分段/随 u 增长） |
| fb 方向强不对称 | triangle +5° 冲到 +10°、负向 −5.67°，方向差 ≈4.3° | 缆预紧/方向死区/重力偏置 → M5 按"方向 × 换向"分组 |
| 换向迟滞证据 | triangle 顶点换向处动态明显（corr 0.93，增益含动态偏置） | M6 前馈"迟滞 sign(q̇) 项"有据可依 |

> 结论：M5 残差分组优先级调整为 **方向 × 换向 > 速度区间 > 工作点**（fb 方向不对称最先显形）。
> 数据来源：`expriment_workspace/M4_verification/`（R2 全段会话可直接用于 F 训练）。

### 7.3 残差结构分解（找优化点的操作步骤）

把 F 的残差按三个维度分组，**残差在哪，优化点就在哪**：

| 分组维度             | 残差集中的含义           | 对应优化动作            |
| ---------------- | ----------------- | ----------------- |
| 运动相位（换向点 vs 匀速段） | 换向点大 → 迟滞/反冲/静摩擦  | 迟滞前馈 `sign(q̇)` 项 |
| 速度区间（低/中/高）      | 低速大 → 静摩擦/死区      | 死区补偿/粘滞补偿         |
| 工作点（小/大角度）       | 大角度非线性 → 增益/柔度标定错 | 2×2 增益矩阵 / 非线性增益  |

**符号标定**（替代 `FLIP_*`）：发 `id=1,+δ` 单轴激励，记录动捕欧拉角变化与方向，得到 `前后/左右 ↔ 欧拉角` 的符号矩阵与增益，存成配置。这是"不猜测"在最低层的落地。

## 8. 前馈优化路线：残差驱动，逐级加复杂度

前馈形态由 §7.3 的证据决定，**从最简单往上加，每级有 A/B 对比**：

| 级   | 模型                          | 触发条件（数据证据）    | 复杂度    |
| --- | --------------------------- | ------------- | ------ |
| 0   | 无前馈（纯反馈 baseline）           | 永远先跑，作基准      | 0      |
| 1   | 增益调度 G(sign(u), \|u\|)（分段常数/参数化） | 残差含方向不对称/幅值增益爬升 | 分段线性 |
| 2   | + 迟滞前馈 `sign(q̇)`           | 换向点残差主导       | 分段线性   |
| 3   | + 速度相关摩擦补偿                  | 低速残差主导        | 查表/分段  |
| 4   | 神经网络 F/g（沿用 feedforward 思路） | 前三级解释不了的残差    | MLP/序列 |

> 上表是**跟踪前馈**级（差分方向，产生/补偿扭矩）。另有**共模预紧**（co-contraction，
> §8.3.2）不属于跟踪前馈——它是两缆同收、不产扭矩、只补松弛并增刚度，属**标定阶段 M3**
> 的前置项，且依赖固件共模通道，须在 M4 开环辨识之前完成。
>
> 级 2/3/4（动态前馈）在 rig2 上统一为**学习型黑盒路线**，见 §8.4——关键差异是
> **架构 1/2/3 一律采用"残差式输出"**（`u_ff = g_static(q_d) + 学习修正`），静态基座固定
> 不可训练，学习项置零即精确退回当前基线。

### 8.1 集成与"不负优化"

- 控制律固定为 `u = u_ff + u_fb`，`u_ff` 是**旁路**，默认 0。
- 反馈环（L3）永远在，前馈只是给反馈"提前量"。
- 每次实验同时记录 baseline（`u_ff=0`）与新方案指标；**新方案只能持平或更好，否则不 merge**。
- 指标统一用 `valuation` 的 MAE/RMSE/最大误差 + rollout FDE（建模层）。

### 8.2 级 1 详解：增益调度 G(x)（M4 数据修正后的形态）

M4 开环实测证明常数增益矩阵**已被证伪**：±5° 有效增益 0.057/0.059 °/offset，为 M3 小幅（0.0357/0.0428）的 **1.4–1.6 倍**；且 fb 方向差 ≈4.3°。故级 1 不是常数矩阵，而是**增益随状态变化的函数**：

```
G(x) = ∂h/∂u          # h: 静态 u→q 关系；G = h 的雅可比，是状态 x 的函数
```

**与 F 模型的关系**：F 的雅可比 `∂F/∂u` 就是增益场的连续版，两者本质同一。但前馈反解用显式 G(x)（轻量、可解释），动态补偿（迟滞/摩擦）才借道 F。

**三种拟合方式（从简到繁）**：

| 方式 | 做法 | 适用 |
| --- | --- | --- |
| 分段常数 | 状态分箱（方向 × 幅度），每箱最小二乘 `G_box = argmin Σ‖δq−G·δu‖²` | 首选，可解释、可反解、数据现成 |
| 参数化函数 | `G(u) = G0 + G1·\|u\| + G2·sign(u) + G3·\|u\|·sign(u)` 一次拟合 | 平滑、外推好 |
| 从 F 提取 | 训 F 后 `∂F/∂u` 任意点取值 | 无限分辨率，但不可解释 |

**状态 x 的维度（M4 优先级）**：方向 `sign(u)` > 幅度 `|u|` > 工作点 `q`（先用 `|u|` 代理）> 换向（属动态，不在静态 G 内）。

**前馈反解**：M3 已证对角占优（交叉项 <0.8%），故每轴标量求倒数即可：

```
u_ff_fb ≈ q_d_fb / G_ff(sign, |u|)，  u_ff_lr ≈ q_d_lr / G_ll(sign, |u|)
```

**分段常数箱划分建议（fb 轴）**：`{+, −} × {|u|≤28 小, ≤56 中, ≤140 大}`（对应 ±1°/±2°/±5°）。大角度（±30°/±60°）箱由滚雪球补数据。

### 8.3 级 1 的模型基础：h(u) 与逆映射 g(q)（M6 实测落地）

#### h(u) 是什么

`h(u)` 是**只考虑稳态的三阶正运动学模型**，用开环数据拟合：

```
h(u) = bias + a1·u + a2·u² + a3·u³
```

- **稳态**：无记忆，是"发 u 等它停住后停在哪"（`h(u) = lim_{k→∞} F 在固定 u 下自由跑的稳态`）；
- **正映射**：u → q；
- **数据驱动**：吸收摩擦/柔度/缆不对称/重力偏置，是"不可信的几何 IK"的真实替代品。

**三项系数的物理含义**（M4+M5 开环拟合）：

| 项 | 物理含义 | fb | lr |
| --- | --- | --- | --- |
| a1·u | 线性增益 | +0.0532 | +0.0561 |
| a2·u² | 方向不对称 | **+0.0000508**（显著） | −0.0000073（弱） |
| a3·u³ | 幅值爬升 | **+0.000000293**（显著） | +0.000000227（弱） |

→ **fb 需要三阶（方向+幅值都显著），lr 接近一阶线性**——两轴独立，数据裁决。

#### bias：中立位偏置

拟合发现 `h(0) = +0.76°`（fb）/ `−0.025°`（lr）：offset=0（固件张紧中立位）时球杆**并不在 0°**，是重力/缆不对称造成。故前馈必须补偿 bias，不能只 `q_d/G`。

#### 前馈用逆映射 g(q)，一步到位

正映射 h(u) 拟合干净（自变量 u 无噪声），但前馈要反解，故拟合**逆映射**：

```
u_ff = g(q_d) = b0 + b1·q_d + b2·q_d² + b3·q_d³
```

- `b0` = 到达 0° 所需 offset（天然含 bias 补偿）；
- 一步到位，无除法、无循环、无分段跳变；
- 增益随 q_d 的关系直接体现（b1 线性 + b2/b3 非线性）。

M6 实测：fb 前馈 `+10°→+125 / −10°→−183`（方向 1.46× + 幅值爬升），`q_d=0→−12.2`（bias）。

#### 这一阶段前馈的意义

1. **静态基座**：`u_ff = g(q_d)` 吃掉静态偏置（bias/方向/幅值），让反馈 PID 只扛动态误差；
2. **撑起闭环**：让闭环在大范围稳定 → 采收敛段 → g 机制 A 数据够了（螺旋迭代的关键一步）；
3. **h 是"认识系统"的正模型**：前馈用它的逆；h 的剩余残差（动态）正是级 2/3/4 的靶点。

> 局限：h 用开环动态数据拟合（非纯稳态），且只到 ±10°；大角度外推需滚雪球补数据。

#### 8.3.1 几何耦合解耦（加性交叉项，级 1.6，数据驱动）

单轴 `u_ff = g(q_d)` 无法表达"球杆绕一轴倾斜后，正交缆绳变松/变紧、改变另一轴
平衡 offset"的几何耦合。几何运动学（`archive/example_code/kinematics/*.m`：4 缆按
90° 排布，缆长 = 大圆弧，球面附着点随球体刚体旋转）给出的是**假设**：耦合应是
加性——一轴倾斜给另一轴加一个平衡 offset，而非缩放另一轴增益。

数据裁决（M14/M15 收敛段，留一会话交叉验证）：

| 模型 | 留出 RMSE fb / lr（offset） | 判据 |
| --- | --- | --- |
| v7 单轴 g(q) | 39.9 / 31.4 | 基线 |
| 乘性 2D（q_fb^i·q_lr^j 全项） | 48.1 / 19.2 | ❌ fb 劣化（乘性项过拟合） |
| **加性交叉（own + poly(q_other)）** | **24.0 / 18.5** | ✅ 两轴 −40%/−41% |

结论：耦合是**加性**的，前馈形态定为

```
u_fb = g_fb(q_fb) + c_fb(q_lr)      # c 为另一轴角度的多项式（无常数项）
u_lr = g_lr(q_lr) + c_lr(q_fb)
```

实现即 `ControllerConfig.gain_cross`（`{"fb": [...], "lr": [...]}`，交叉项系数）。
它与 v7 严格兼容：`gain_cross` 缺省时退回 v7；`fit_controller --couple` 只在留出
验证不劣于 1D 时才写入（护栏）。

> 重要校正：早先单变量斜率测出的"lr 增益随 |fb| 从 −0.062 翻到 +0.011（符号翻转）"
> 是**混杂假象**——沿圆轨迹 u_fb 与 u_lr 相关，未控 u_fb 的单变量斜率被污染。部分
> 回归（控 u_fb）后本轴增益稳定 ≈+0.074，交叉项在前向图小（∂q_lr/∂u_fb≈−0.013），
> 但因本轴增益小（det≈0.074²），反解后交叉项被放大为 ≈+1.9 offset/deg，与实测一致。

#### 8.3.2 共模预紧（co-contraction，数据驱动，M3 阶段）

##### 动机：与 gain_cross 是两类不同的耦合

§8.3.1 的 `gain_cross` 补的是**奇对称**稳态耦合（重力/锚点不对称导致的张力再分配）。
几何运动学（`archive/example_code/kinematics/*.m`）还揭示另一类**偶对称共模**效应：
绕一轴倾斜会使正交对两根缆的几何距离**同时缩短**（A=20° 时 ≈0.835mm，且 ΔL2=ΔL4 严格
相等）。缆只能拉不能推 → 若缩短量超过中立位预紧预算，两缆同时松弛 → 换向死区 + snap。

| | gain_cross（级 1.6） | 共模预紧（本节） |
| --- | --- | --- |
| 对称性 | 奇（∝ q_other 一次项为主） | 偶（∝ q_other 二次项为主） |
| 作用方向 | 差分：一收一放，产生/补偿扭矩，改稳态角 | 共模：两缆同收，净扭矩≈0，只补松弛、增刚度 |
| 数据来源 | 收敛段 (q, u) 留出拟合 | 力传感器张力 / 换向死区宽度 |
| 固件依赖 | 现有差分通道即可 | **需新增共模通道**（当前固件无） |

> 实测佐证：数据拟合的 `gain_cross` 是奇函数（`c_lr(q_fb)=+1.86·q_fb`，二次项≈0），
> 而几何松弛是偶函数（∝q_fb²）——奇偶都对不上，说明两者是**不同机制**，`gain_cross`
> 补不了共模松弛。这与"实际行为与几何运动学差距大"的判断一致，系数必须由数据定。

##### 函数形式

```
u_1-3 = ±u_fb + c_fb(q_lr)       # 两缆同收 c_fb(q_lr) ≥ 0
u_2-4 = ±u_lr + c_lr(q_fb)       # 两缆同收 c_lr(q_fb) ≥ 0

c_axis(q_orth)：偶函数 c(+q)=c(−q)，恒 ≥ 0（只紧不松）；不产净扭矩，只抬高旋转刚度
```

##### 数据驱动拟合（不信任几何的 0.835mm，系数全由数据定）

判据统一为**张力不落零**。两条等价路径：

1. **力传感器直测（首选）**：开环扫过 2D 工作区，读每根缆张力 `T_i(q_fb,q_lr)`
   （`collect/sensors/force.py`，ch1–ch6 → 缆张力映射）。则
   `c_axis(q_orth) = argmin_{c≥0} c  s.t.  min_i T_i ≥ T_min`，即"使四缆张力都守住
   下限 T_min 的最小共模收紧量"。
2. **换向死区标定（备选）**：triangle/eight 换向处测死区宽度 `δ_axis(q_orth)`
   （"舵机动了 Δu 而球角不变"的量），`c_axis = δ_axis + margin`。

参数化：`c_axis(q_orth)` 用**低阶偶多项式** `c0 + c2·q_orth² + …`（或按 |q_orth| 分箱
查表）拟合；几何模型只提供"偶、对称、∝q²"的**函数形状先验**，系数全部由力/死区数据
拟合。`margin`/`T_min` 为超参，由 A/B 决定（过度预紧增摩擦、抬刚度，见下）。

##### 环节安排（必须前置，先于开环辨识）

共模预紧改变系统刚度与摩擦 → 会移动弹性模态频率、改变 `h(u)` 与增益。因此它**不能**
当作"级 1.6 之后叠加的一项"，而必须作为**标定阶段 M3 的前置步骤**，先于 M4 开环辨识：

```
M3 标定：符号映射 + 【新增】力传感器预紧标定 → c_fb(q_lr), c_lr(q_fb)
M4 开环辨识：在【已预紧】系统上扫频 → h(u) → g(q)
级 1（g(q)）→ 级 1.6（gain_cross）→ 级 2/3（迟滞/摩擦）   # 全部在已预紧系统上辨识
```

> 硬依赖与连锁：
> - 固件协议已升级为 **v2 单帧多通道**（`hardware/protocol.py`：`0xAA | CMD | CH1..CH4
>   | 0x55`，11 字节，4 通道原子发布，消除旧多帧"半更新命令"）。固件只需把 4 个 int16
>   一次性写入 4 个舵机，**无需理解差分/共模语义**（语义在 host 的 `mix_channels()`）。
> - 预紧后**必须重跑 Kp/Kd 扫描**：预紧抬高旋转刚度 → 弹性模态频率上移，旧 PID 参数
>   （围绕 1.5Hz 调出来的）失效，需重新整定。

### 8.4 学习型动态前馈（黑盒，rig2 阶段 D0–D3）

稳态前馈收敛后（§8.3：g(q) 已 merge、级1.6 经真 2D 覆盖 + 实机 A/B 否决、静态残余补偿无收益），
剩余残差**转向动态**。本节定义用学习型黑盒模型补动态残差的路线——对应 §8 级 2/3/4 的现代形态。

#### 8.4.1 问题形式化：前馈 = 被控对象的动态逆

```
u_ff(t) = F⁻¹( q_d(t), q̇_d(t), q̈_d(t), 内部状态 )
```

所有架构差异只是"用哪条路逼近这个逆"。**rig2 实测证据**：2D 富激励（67999 样本）对 PID 残余
回归，`sign(q̇)` 系数 +7.7/+8.5 offset（库仑量级最大）、`q̇` 系数 +0.24/+0.21、
`q̈≈0`，而 **R² 仅 0.27** → 瞬时 (q, q̇) 只能解释约 1/4 残余，**其余需要记忆**。

#### 8.4.2 组合原则：残差式输出（不放弃稳态基座）

**核心原则：`u_ff = g_static(q_d) + [任意模型].correction(·)`。** 静态基座固定不可训练，
网络只学修正量。这是**输出定义的选择，不是某个架构的专利**：

| 架构 | 朴素写法（丢掉稳态） | **残差写法（保留稳态）** |
| --- | --- | --- |
| 1 残差 MLP | — | `u_ff = g(q_d) + f_θ(q_d, q̇_d)` |
| 2 序列/记忆（TCN/GRU） | `u_ff = π_θ(历史)`（须重学静态映射） | `u_ff = g(q_d) + π_θ(历史)` |
| 3 前向 F + 反解 | 反解**绝对 u**（静态被 F 吸收） | 反解**修正量** Δu：`F(q_d,q̇_d, g(q_d)+Δu)=q̈_d` |

四个理由：① 静态占驱动量 **98%**（RMS 236.9/240.5），重学是浪费；② 修正项置零 = **精确退回当前基线**
→ 天然满足"每级只进不退"；③ 修正量仅 ±15% 量级 → 训练稳、可 clip 兜底；④ 静态可解释、修正可旁路回滚。

#### 8.4.3 输入边界：参考量（纯前馈）vs 实测量（状态反馈）

| 输入 | 性质 | 说明 |
| --- | --- | --- |
| **解析参考** `q_d, q̇_d, q̈_d`（轨迹生成器直接给） | **纯前馈** | 无闭环稳定性风险；参考量**零噪声**（不需 IMU、不需差分） |
| 实测 mocap / IMU / 张力 | 实为**状态反馈** | 引入闭环稳定性问题，须单独分析（D3 再做） |

**D1/D2 严格用参考量**：保持纯前馈、无闭环风险，也避免闭环混淆（模型不会去偷看误差）。
> IMU 陀螺的真正价值在**反馈的 D 项**（免差分、低噪，绕开 KD 放噪的教训），不在前馈；
> 参考速度是解析量，比 IMU 更干净。

#### 8.4.4 三个必须设计规避的坑（都是本项目已踩过的）

1. **闭环混淆（最大风险）**：闭环里 `u = PID(q_d − q)`。若拿 `(q_d, q) → u` 训练，学到的是
   **PID 本身**。→ **监督目标必须是"状态 → u_总"**（收敛段里 `u_总 ≈ 目标状态所需 u`），
   不是"误差 → u"。验证兜底：若只学会模仿 PID，加入前馈会**双重补偿** → 实机 A/B 必劣 → 被判据抓住。
2. **退化（rig2 级1.6 的血泪）**：轨迹退化（圆是 1D 流形 → `q_other` 与本轴速度同相位 → 拟合出
   **错误符号**）；速度退化（匀速 → `Kv·q̇` 与 `Kc·sign(q̇)` 共线 → 分不开）。
   → 激励必须**真张成被拟合空间**（2D 网格/随机轨迹 + 速度阶梯）。
3. **微分噪声（KD 那一课）**：q̇/q̈ 用动捕差分 → 噪声放大。→ 前馈用**解析参考量**（零噪声）；
   若必须用实测，优先 IMU。

#### 8.4.5 数据采集设计（针对学习，不是针对参数拟合）

| 批次 | 类型 | 目的 | 关键要求 |
| --- | --- | --- | --- |
| **A** | 开环宽带（多正弦/PRBS/chirp）× 多幅度 ±5/10/20/30° | 学前向 F、激出 2Hz 模态与非线性 | 频率覆盖到 5Hz；单轴 + 2D |
| **B** | 闭环**速度阶梯**（同幅度 0.05/0.1/0.2/0.4Hz） | 逆映射监督覆盖 \|q̇\| 区间 | 固定 PID + 当前稳态前馈 |
| **C** | 闭环**随机富轨迹**（多频 Fourier 叠加） | (q, q̇) 空间覆盖最大化 | 幅度包络限制在工作区 |
| **D** | 闭环变速/路点 | 覆盖驻留 + 高速过渡 | 含换向 |

四批均开 `--force-port` + IMU，四路（mocap/imu/force/servo）按时间戳对齐落盘。

#### 8.4.6 验证协议（级1.6 的教训直接固化）

1. **留出"轨迹"而非留出"时间"**——考泛化到新轨迹（未见过的速度组合）。
2. **实机 A/B 隔离唯一变量**：段0 = 当前稳态前馈，段1 = 稳态 + 学习项，**`g_static` 系数完全相同**。
3. **测试轨迹必须含变速**，否则动态项未被激励、测不出效果。
4. **离线指标不作判据**：级1.6 已证"留出 RMSE 衡量拟合优度、不衡量闭环收益"（离线 −7.5% 通过
   护栏，实机反劣 +8~11%）→ **只信实机 A/B**。
5. **零退回保证**：修正项权重清零 = 当前基线，可随时回滚。

#### 8.4.7 落地顺序

```
D0  采集设施：速度阶梯轨迹 + 随机 Fourier 轨迹（control/trajectory.py）
    + 四路（mocap/imu/force/servo）时间戳对齐 merge 工具
D1  架构1 残差 MLP（输入 q_d,q̇_d；在 g_static 上叠修正）→ 实机 A/B
    （预期：捕获瞬时可解释部分 ~25%，先验证管线与判据）
D2  架构2 序列模型（历史窗，抓迟滞 R² 剩余 ~75%）→ 实机 A/B
D3  规模化：更多数据 / 张力与 IMU 特征消融 / 状态自适应（混合）前馈
```

## 9. 数据架构：开环 × 闭环 × 前馈建模

开环与闭环不是二选一，而是覆盖状态空间的两个正交半区，共同喂给 §8 的前馈建模。

### 9.1 状态空间的两半区（为何缺一不可）

| | 位形轴（q, q̇） | 指令轴（u） |
| --- | --- | --- |
| 开环 | 浅：只能"扫过"，**不能驻留**非零工作点 | 宽：u 主动设计，可大差分/多频率/多方向 |
| 闭环 | 精确：q 被锁定在 q_d，可驻留任意工作点 | 窄：u 只是维持 q_d 的刚需值 |

物理本质：缆驱动开环没有平衡保持机制，发差分 offset 球杆会"摆过去再回来"（自由响应），停不住在非零工作点；只有闭环反馈能把球杆"钉"在 q_d。

**深层矛盾**：最终目标"工作空间内任意合理轨迹"最难的段是**低速段 + 大角度驻留段**（静摩擦最强、增益非线性最强），而这两处恰好是开环扫频的数据盲区。因此"开环能否覆盖闭环状态"的答案是：**不能，两者是拼图的两半**。

### 9.2 数据分工（三个用途，不混）

| 数据来源 | 喂给 | 不能用来 | 原因 |
| --- | --- | --- | --- |
| 开环扫频 | 前向 F 主训练 | 训 g（无 q_d↔u 真值） | u 主动设计、与噪声独立 → 干净因果 |
| 闭环收敛段 | 逆模型 g 经验监督 | 训 F 主模型 | `u_log ≈ 维持 q_d 的正确指令`，是 g 的直接真值 |
| 闭环全段 | baseline 度量（A/B 尺子） | — | 记录 (q_d, q_m, u) 作对照 |

**闭环辨识偏置**：闭环 `u` 是对 `q_m` 噪声的反应（`u = PID(q_d − q_m)`），u 与噪声相关，直接喂 F 会学到"噪声经反馈回路的假动力学"，产生系统性偏置。这是闭环结构决定的，不是数据质量问题。

### 9.3 工作点局部激励（覆盖任意轨迹包络）

覆盖"任意合理轨迹"完整包络的正确形态，不是单一开环大扫频，而是：

```
闭环"去"：把球杆稳定到工作点 q*（覆盖大角度驻留，开环去不了）
   +
开环"扰"：在 q* 附近叠加小幅度 dither（辨识该工作点的局部动态）
```

- 工作点覆盖（0°/10°/30°/60°… 逐个去）由闭环完成；
- 局部动态（该工作点的增益/死区/迟滞/频率响应）由开环 dither 完成（保持干净因果）；
- 两者拼起来覆盖：每个工作点 × 每个速度档 × 每个方向。

扫频范围面向工作空间全包络（滚雪球扩展到 ±60°），**不锚定单一测试轨迹**；但盲区（低速驻留）不在 M4 开环扫频里解决，由工作点局部激励补。

### 9.4 前馈模型的构建数据流（F/g 双模型）

控制律 `u = u_ff + u_fb`，前馈 `u_ff` 由两个可微模型构成；`u_linear(q_d)` = §8 L1 级（2×2 增益矩阵，M3 已测初值）作线性基座，g 学残差：

| 模型 | 方向 | 训练真值 | 角色 |
| --- | --- | --- | --- |
| 前向 F | u → q | 有（动捕 q_m 直接真值） | 可微仿真器，提供 ∂q/∂u |
| 逆 g | q_d → u | 无（数据里没有"正确 u"列） | 前馈指令生成 |

逆模型没有直接真值，必须**借道 F**：

- **机制 A（收敛段经验监督，稳、外推弱）**：闭环收敛段 `u_log(k)` 即"维持 q_d 的指令"，`Δu^gt = u_log − u_linear(q_d)` 直接监督 g，作预训练。
- **机制 B（经冻结 F 反传，主推，泛化强）**：g 输出指令序列 → 冻结 F 自由跑出 q̂ → 与 q_d 比轨迹误差，链式法则 `∂L/∂q̂ · ∂F/∂u · ∂g/∂φ` 反传。F 的雅可比替代"正确 u"，且能泛化到任意合理轨迹。

完整数据流：

```
开环扫频 + 工作点 dither ──(u,q 干净因果)──► F: u→q（多步 rollout loss）
                                                  │ 冻结，提供 ∂F/∂u
闭环收敛段 ──(u_log≈真值)──► 机制A 预训练 ──► g: q_d→u ──► u_ff = u_linear + g
闭环全段 ──────────────────────────────────────────► u = u_ff + u_fb（baseline 度量）
```

### 9.5 激励信号需补齐的判别性

现有 `sweep_segments`（amp×freq Lissajous）覆盖增益/速度，但缺两类判别性激励：

1. **往返 chirp/三角波** → 暴露迟滞（滞回环宽度）。
2. **微幅阶跃** → 暴露静摩擦死区。

`excite/signals.py` 需在 Lissajous 基础上补齐这两类，输出仍是差分 offset。

### 9.6 安全监护（guardian）

- **限位定义在关节角空间**：动捕实测的前后/左右角超过 **70°** 即急停（回中位 `send_pair(0,0)`）。
- **不用 offset 限幅作安全界**：offset → 关节角增益未知（这正是要数据驱动辨识的量），不能预先假设 offset 与角度的关系。
- 监护为独立线程/独立判定，不依赖控制循环是否正常。

## 13. 螺旋迭代优化 pipeline（M6 起总纲）

前馈优化不是线性阶段（M6→M7 一次做完），而是**螺旋迭代**：每轮同时推进 F 与 g，用两个闭环信号牵引下一轮，任何一步不允许"负优化"。

### 13.1 核心原则

1. **F 与 g 并行，不是先后**：g 有两条路径——机制 A（收敛段经验监督）不依赖 F，随时可做；机制 B（经 F 反传）需等 F 够准。故每轮同时推进两者。
2. **数据-复杂度结对爬升**：不"先攒够数据再动"。数据量支撑到哪级复杂度，就先做哪级；残差/实机反馈指出不足，再补数据升复杂度。
3. **每轮产出可上实机 A/B 的前馈**：F 是手段，前馈提升是目的。避免"永远优化 F 不上实机"的陷阱。

### 13.2 每轮螺旋的步骤

```
① 数据      现有 + 上一轮"残差指引"补的数据
② F 升级    按残差结构逐级：线性 → 分段线性 → 序列
③ 残差分解  验证升级是否解释了目标残差（离线闭环信号）
④ g 构建    机制 A（恒可做）→ 机制 B（F 够准后）
⑤ 实机 A/B  u = u_ff + u_fb，对比 baseline（u_ff=0）
⑥ 判据      两个信号决定下一轮：
    · 残差转移了吗（③ 的分解结构变化）
    · A/B 提升了吗（⑤ 指标 ≥ baseline）
```

### 13.3 两个闭环信号（循环不跑偏的兜底）

| 信号 | 快慢 | 作用 |
| --- | --- | --- |
| 离线：残差分解 | 快、无需实机 | 验证 F 升级方向对不对（如方向分段后 dir_pos≈dir_neg） |
| 实机：A/B 指标 | 慢、需实机 | 前馈上线是否真的有用（≥ baseline） |

两个信号一快一慢、一离线一实机，互相印证。

### 13.4 "不出现负优化"的机制

- 控制律固定 `u = u_ff + u_fb`，`u_ff` 是**旁路**，默认 0；
- 反馈环永远在，前馈只是给反馈"提前量"；
- 每级前馈上线前先跑 `u_ff=0` baseline，上线后指标**只能持平或更好，否则不 merge**；
- **所有实机前馈实验一律"同一轨迹跑两份"**：baseline（`u_ff=0`）+ 前馈，A/B 对比，不许只跑前馈无对照；
- 指标统一：`valuation` 的 MAE/RMSE/max + rollout FDE。
