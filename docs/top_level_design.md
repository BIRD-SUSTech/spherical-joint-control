# 缆驱动球关节系统 —— 顶层重构设计文档

> 状态：设计共识稿（讨论收敛版，未实现代码）
> 对象：2-DOF 四缆绳驱动球杆系统（物理模型不变：球杆绕球心两自由度摆动——前后 / 左右，期望工作范围 ≤65°）
> 前置：本文档取代 `docs/feedforward_design.md` 的架构地位；后者降级为"前馈子系统的历史设计快照"，其中与本文冲突处以本文为准。

## 1. 背景与目标

项目从"能跑的最小闭环"逐步堆叠成多套并存实现，同一概念有多个互相矛盾的口径，已到必须从头梳理的程度。本文档做四件事：

1. 明确**新基座**：以 `example_code/steering_motor`（已验证的最小闭环 + STM32 固件）为唯一出发点；
2. 定义**唯一事实源**（Single Source of Truth）：每个物理/数据概念只保留一个口径；
3. 给出**分层架构**：每层可独立验证、可回退，新模块以"旁路"接入，保证不"负优化"；
4. 制定**数据驱动找优化点**的方法论：不猜测死区/静摩擦，让固有问题在数据中显形，再决定建模复杂度。

## 4. 新基座：底层约定（唯一真值源）

以下约定以 `example_code/steering_motor` 的**固件实际行为**为准（`Core/Src/main.c` + `usart.c`），是 L0 层不可再分的物理事实。

### 4.1 串口协议

- 帧格式：`0xAA | id(1B) | int16_be(2B) | 0x55`，共 5 字节。
- `id=1` → 前后对 `Coupled_Servo(CH3, CH1, S3_MID, S1_MID, offset, comp)`
- `id=2` → 左右对 `Coupled_Servo(CH4, CH2, S4_MID, S2_MID, offset, comp)`
- `id=0` → **完全放线**（四路减 `RELAX_OFFSET`，杆会垂落），**仅用于急停/guardian（关节角超限）**，正常收尾不用。
- 运行约定：正常退出（含 Ctrl+C）回中位 `send_pair(0,0)`（offset=0 → 固件 `Sx_MID` 张紧中立位）保持缆张紧；`id=0` 松缆只留给 guardian 急停。
- 耦合在**固件内**完成：一端 `+offset`、另一端 `-offset`；主机只发 2 路差分。

### 4.2 指令空间

- 指令 = **PWM offset（int16）**，物理上是舵机脉宽的微秒级偏移。
- 固件 `MOVE_RANGE` 宏未实际使用，**删除**；offset 不做固有限幅，安全界定义在**关节角空间**（§9.2，阈值 65°）。
- offset → 关节角的增益未知，由标定确定（§7.3），也是前馈 L1 级（2×2 增益矩阵）要辨识的对象；增益标定前，激励幅度逐步保守放大。
- 中位脉宽：`S1_MID=1500, S2_MID=1600, S3_MID=1500, S4_MID=1500`（`S2_MID=1600` 是硬件标定差异，保留）。
- 共模预紧 = 固件 `Coupled_Servo` 的 `comp` 参数（当前 `main.c` 写死 0）。预紧是**固件层共模**，不是主机层量。

### 4.3 最小闭环参考行为（`CloseLoop/main.py`）

- 双独立 PID（左右、前后），输出单位 offset，`KP=8, KI=1, KD=2.5, DB=0.2, AP=0.3`。
- 动捕读取：`PyGetLastFrameOfMocapData()` 轮询最后帧，取 SDK 扩展欧拉角；刚体按 `rigid_bodies[0]` 下标取。
- 左右（id=2）← 动捕 `pitch`，前后（id=1）← 动捕 `roll`（此为 example_code 实测，仍需 §7.3 标定确认映射与符号）。
- 控制频率 ≈ 100Hz（非严格定时）。

### 4.4 关键简化

`excitation.py` 的差分/共模思想保留，但编码函数从"差分/共模 → 4 路归一化"简化为"两轴差分 → 2 路 offset"。共模（预紧）下沉到固件 `comp`。

## 5. 分层架构（L0–L5）

```
L0 硬件/协议层   协议帧编解码、串口、舵机 offset 限幅、放松/急停、动捕读帧
L1 采集层        统一 CSV schema + 时间戳 + segment 语义 + 多线程采集编排
L2 激励层        开环差分激励（Lissajous/chirp/阶跃/往返）+ 安全监护
L3 控制层        最小闭环 PID（唯一控制器，u_fb）
L4 建模层        前向 F / 残差结构分解 / 前馈 g（纯离线，读 L1 数据）
L5 集成层        u = u_ff + u_fb，u_ff 默认 0（可关）
```

### 5.1 各层职责与真值源

| 层   | 职责                      | 唯一真值源                                                  |
| --- | ----------------------- | ------------------------------------------------------ |
| L0  | 协议、串口、offset 限幅、急停、动捕读帧 | `example_code` 固件协议（§4）                                |
| L1  | 采集编排、CSV 落盘、时间对齐、分段     | `data_collection` 的 schema/编排设计（复用其设计，换 L0 驱动）         |
| L2  | 激励轨迹生成、安全监护             | `control_model/excitation.py` 的差分/共模思想（复用思想，输出 offset） |
| L3  | 反馈控制                    | `example_code/Scripts/CloseLoop` 的 PID 行为（唯一控制器）       |
| L4  | 前向/前馈建模                 | `feedforward/` 的 pipeline 设计（复用 F/g 与 rollout 评估思路）    |
| L5  | 前馈叠加与 A/B               | 新增，旁路开关                                                |

## 7. 数据驱动方法论：不猜测，让问题显形

### 7.1 核心原则

**"不猜测" ≠ "不建模"，而是"每个假设都配一个判别性实验，用数据裁决"。**

- 假设"存在静摩擦/死区" → 判别实验：微幅阶跃，测"offset 变化而姿态不动"的死区宽度（可直接量化）。
- 假设"存在换向迟滞" → 判别实验：往返 chirp/三角波，测 `q(u)` 上升/下降沿滞回环宽度。
- 假设"增益/柔度标定错" → 判别实验：准静态扫幅，测 `q` 对 `u` 的斜率与标称是否一致。

### 7.2 已有证据（离线前向建模 + M1 实机观察）

前向模型 F 的现有结论已经能回答一半问题：

- **1-step 误差 ≈ 0.10°/0.14°**（前后/左右），已接近动捕噪声地板 → 前向映射本身不难学。
- **free-running rollout 发散严重**：`real_60seg` rollout MAE 0.71°/1.21°、FDE 欧氏 5.8°；`real_randomval` 更差。

**解读**：单步能拟合、多步漂移 = 系统存在**记忆效应**（迟滞/静摩擦/缆松弛/舵机动态），而非纯静态非线性。这**正是"固有问题"的量化证据**——不需要猜。

M1 实机（`--hold` 阶跃，2026-09-05）补充的直接观察，全部指向同一批固有问题：

| 实机观察 | 量化 | 指向的固有问题（§7.3 对应动作） |
| --- | --- | --- |
| 轴间瞬态耦合 | lr 阶跃 5° 扰动 fb ≈1.5° | 2×2 增益/解耦（前馈 L1 级） |
| 增益非线性 | fb 5° 稳态 ≈0.041°/offset vs 近中位 ≈0.023°/offset | 反对单一标量增益，分方向/工作点标定 |
| 低幅游走 | fb 5° 位 std≈0.20°（> 噪声地板 0.06°），out 58–102 游走 | 疑似静摩擦微极限环 |
| 阶跃超调 | 5° 目标冲到 ≈8.6°（≈+72%），1.6–2.0s 收敛 | PID 整定 / 前馈欠补偿 |
| 持中位 DC 偏置 | (0,0) 需 out fb=−36 / lr=−25 | 重力/不对称补偿（可进前馈基座） |

> 数据来源：共享目录 `expriment_workspace/M1_verification/`（实验记录 + `data/*.csv`）。

### 7.3 残差结构分解（找优化点的操作步骤）

把 F 的残差按三个维度分组，**残差在哪，优化点就在哪**：

| 分组维度             | 残差集中的含义           | 对应优化动作            |
| ---------------- | ----------------- | ----------------- |
| 运动相位（换向点 vs 匀速段） | 换向点大 → 迟滞/反冲/静摩擦  | 迟滞前馈 `sign(q̇)` 项 |
| 速度区间（低/中/高）      | 低速大 → 静摩擦/死区      | 死区补偿/粘滞补偿         |
| 工作点（小/大角度）       | 大角度非线性 → 增益/柔度标定错 | 2×2 增益矩阵 / 非线性增益  |

**符号标定**（替代 `FLIP_*`）：发 `id=1,+δ` 单轴激励，记录动捕欧拉角变化与方向，得到 `前后/左右 ↔ 欧拉角` 的符号矩阵与增益，存成配置。这是"不猜测"在最低层的落地。

## 8. 前馈优化路线：残差驱动，逐级加复杂度

前馈形态由 §7.3 的证据决定，**从最简单往上加，每级有 A/B 对比**：

| 级   | 模型                          | 触发条件（数据证据）    | 复杂度    |
| --- | --------------------------- | ------------- | ------ |
| 0   | 无前馈（纯反馈 baseline）           | 永远先跑，作基准      | 0      |
| 1   | 2×2 差分增益矩阵                  | 残差主要是静态增益/耦合错 | 线性     |
| 2   | + 迟滞前馈 `sign(q̇)`           | 换向点残差主导       | 分段线性   |
| 3   | + 速度相关摩擦补偿                  | 低速残差主导        | 查表/分段  |
| 4   | 神经网络 F/g（沿用 feedforward 思路） | 前三级解释不了的残差    | MLP/序列 |

### 8.1 集成与"不负优化"

- 控制律固定为 `u = u_ff + u_fb`，`u_ff` 是**旁路**，默认 0。
- 反馈环（L3）永远在，前馈只是给反馈"提前量"。
- 每次实验同时记录 baseline（`u_ff=0`）与新方案指标；**新方案只能持平或更好，否则不 merge**。
- 指标统一用 `valuation` 的 MAE/RMSE/最大误差 + rollout FDE（建模层）。

## 9. 开环扫频 × 最小闭环的分工

两者不是二选一，是分工：

| 模式   | 职责                                            | 产出           |
| ---- | --------------------------------------------- | ------------ |
| 开环扫频 | 认识系统：干净因果 I/O（`u` 主动设计、与噪声无关）                 | 辨识 F、定位固有问题  |
| 最小闭环 | ① 安全兜底（让开环敢扫更大范围）② 产生"收敛后 `u`"作逆模型监督 ③ 前馈最终宿主 | 稳定运行 + 收敛段数据 |

### 9.1 激励信号需补齐的判别性

现有 `sweep_segments`（amp×freq Lissajous）覆盖增益/速度，但缺两类判别性激励：

1. **往返 chirp/三角波** → 暴露迟滞（滞回环宽度）。
2. **微幅阶跃** → 暴露静摩擦死区。

`excite/signals.py` 需在 Lissajous 基础上补齐这两类，输出仍是差分 offset。

### 9.2 安全监护（guardian）

- **限位定义在关节角空间**：动捕实测的前后/左右角超过 **65°** 即急停（发 `id=0` 放松）。
- **不用 offset 限幅作安全界**：offset → 关节角增益未知（这正是要数据驱动辨识的量），不能预先假设 offset 与角度的关系。
- 监护为独立线程/独立判定，不依赖控制循环是否正常。
