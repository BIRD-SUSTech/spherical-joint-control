## 0. 结论速览

| 路线                              | 判定            | 依据                          |
| ------------------------------- | ------------- | --------------------------- |
| **反解 F**（GRU 时序 F + 运行时对 u 求逆）  | ❌ **结构性不可辨识** | ①②③（见 §3）                   |
| 加数据/换激励/换模型容量                   | ❌ 救不了         | 根因与数据量无关（§3.3）              |
| **直连式 Δu**（GRU：期望轨迹+传感器历史 → Δu） | ✅ 可辨识，已交付     | 标签定为"超出静态基座的动作量"，期望轨迹是真外生信号 |

**一句话根因**：本平台舵机是**位置控制**——指令 u(t) 就是实测关节角 q(t+8拍) 的
线性像（实测 r = 0.96~0.99，§3.3）。历史特征里的 q 已完全暴露 u，因此
`(历史, u)` 相对历史**零信息增量**，∂F/∂u 无法辨识——**与激励类型、数据量、
模型容量均无关**。

---

## 1. 原定架构（反解 F）

```
h_t = GRU( x_{t-L+1..t} )            # 历史编码：状态 + IMU + 张力
ŷ_t = head( [h_t , u_t] )            # 头显式吃【当前动作】u_t
runtime:  find u  s.t.  head(h, u) = q̈_d   （阻尼牛顿，2 维）
```

x 每拍 16 维：`q(2) q̇(2) u_prev(2) | 陀螺(3) 加计(3) | 张力 ch1–4(4)`。

## 2. 方法：三组**独立**证据

反解 F 的风险不在"模型准不准"，而在**循环性**（模型学成"从历史猜 u"而非
"从 u 算加速度"）。三条判据互不依赖：

| 判据         | 做法                                                 | 否决条件           |
| ---------- | -------------------------------------------------- | -------------- |
| ① 反循环对照    | 训练时**打乱**头部 u_t，或**完全去掉** u 输入                     | 留出 RMSE 几乎不变   |
| ② 灰箱参照     | 独立线性回归 `Δ ~ [1, q, q̇, u]` 得 ∂/∂u，与 GRU 的 ∂F/∂u 对照 | 量级/符号对不上       |
| ③ 自洽 + 反事实 | 用**记录到的**目标反解 → 解出的 u 应≈记录 u；再用期望轨迹目标反解            | Δu 与 u 自身波动同量级 |

工具：`model/validate_forward_inverse.py`（`--ctrl-shuffle-u` 跑判据①）。

## 3. 结果

**训练质量本身是好的**（不是拟合问题）：视界模式留出 Δq̇ RMSE
`19.9→6.2 (fb) / 21.1→7.2 (lr)`，即 **−69%**。

### 3.1 判据①：模型根本没用 u_t

| 数据                    | 目标       | 含 u           | 打乱 u          | 退化                |
| --------------------- | -------- | ------------- | ------------- | ----------------- |
| 闭环 D0（4 会话）           | q̈ 单拍    | 25.04 / 24.29 | 24.59 / 24.45 | **−1.8% / +0.6%** |
| 闭环 D0（4 会话）           | Δq̇ 视界15 | 6.56 / 6.65   | 6.48 / 6.65   | **−1.3% / −0.0%** |
| **开环** snowball（2 会话） | Δq̇ 视界15 | 5.90 / 5.79   | 5.92 / 5.83   | **+0.2% / +0.7%** |

**去掉历史里的 u 列**（逼 u 只能从头部进）：退化 **+0.0% / +0.0%**，且
Jacobian 交叉项爆到 **−200**、`|det|≈2500`、**100% 反解不出**（残差 >1）。

### 3.2 判据②：灰箱与 GRU 对不上（且都远小于物理预期）

| 会话     | 灰箱 ∂Δq̇/∂u       | GRU ∂F/∂u |
| ------ | ---------------- | --------- |
| 200340 | +0.52 (R²=0.865) | +0.10     |
| 200639 | +0.53 (R²=0.848) | +0.07     |
| 200928 | +0.68 (R²=0.841) | +0.10     |
| 201038 | +0.55 (R²=0.818) | +0.09     |

**差 5~7 倍**。灰箱那 0.5 是**混淆**：它只有当前 (q, q̇) 作状态，u 实为轨迹相位的
代理；GRU 有 10 拍历史 + IMU，把同一份信息归给了历史 → 归因出的 ∂F/∂u 接近 0。
（顺带修正前一处错误估计：`ω_n²·γ ≈ 10 °/s²/offset` 是高估；真实 ∂q̈/∂u ≈ 0.5。）

### 3.3 判据③ + 根因：u 是实测角的线性像

**反事实反解**（目标 = 期望轨迹的 q̈_d）：|Δu| 中位 **60~137 offset**，
p95 达 **600 offset**，|u|max 到 **1055**，未解出率最高 100%——
解出的 u 与"u 自身波动（90~280）"同量级 → **等同随机**。

**根因（决定性）**：舵机位置环使实测角直接暴露指令。

| segment | u 峰 (offset) | q 峰 (°) | q/u 增益 | r( u(t), q(t) ) 零滞后 | 最优滞后       |
| ------- | ------------ | ------- | ------ | ------------------- | ---------- |
| 0       | 243.0        | 20.37   | 0.0813 | **0.9763**          | u 领先 q 8 拍 |
| 2       | 325.0        | 28.86   | 0.0838 | **0.9886**          | 8 拍        |
| 4       | 243.0        | 23.66   | 0.0863 | **0.9861**          | 8 拍        |
| 5       | 243.0        | 24.33   | 0.0824 | **0.9592**          | 8 拍        |

即 **u(t) ≈ q(t+8拍)/增益**，r≈0.98。模型要用"未来运动"预测，直接用测量到的 q
（下游、无指令-执行失配）严格优于用 u。**故 ∂F/∂u 不可辨识是结构性的。**

> 附带修正一个尺度误判：控制权限在**速度尺度（~τ=0.21s）**，不在加速度尺度（10ms）。
> 这解释了为什么「反解单拍 q̈」病态，而加性速度前馈 `c·q̇_d` 有效且可辨识。

## 4. 为什么换激励救不了

即使 u 外生（开环、随机相位多正弦），u 仍是实测位置的线性像——
**可辨识性缺失来自"位置控制"这一物理结构，不来自激励**。
判据①在开环数据上同样为 0（§3.1 第 3 行）。

## 5. 替代方案：直连式 Δu（已交付）

标签换成**超出静态基座的动作量**，输入保留"纯模型 + 传感器历史"：

```
Δu_t = u_recorded(t) − u_base(q_d, q̇_d)                       # 标签
Δu_t = GRU( 历史窗 L 拍 )[ q,q̇ | q_d,q̇_d,q̈_d | 陀螺,加计 | 张力 ch1–4 ]
runtime:  u_ff = u_base + clip(Δu, ±cap)     cap=0 → 逐位退回基座
```

- **可辨识**：期望轨迹 q_d 是真外生信号（控制器自己给的，不受实测影响）。
- **无需求逆** → 没有非单射/噪声放大问题（自检实测：u→q̈ 映射**非单射**，
  u*=[37,−14] 会解到输出相同的 [2.8,−1.4]；若非要反解，**必须从静态前馈起解**）。
- **零回归**：cap=0 逐位退回基座（残差式）。
